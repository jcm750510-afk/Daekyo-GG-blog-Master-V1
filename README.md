# GPT용 눈높이 블로그 프롬프트 마스터 V3

대교 눈높이 교육 콘텐츠를 위한 **GPT 기반 블로그 주제 추천 + 후킹 제목 + 네이버 블로그 작성 프롬프트 생성 웹앱**입니다.

GitHub Pages에서 동작하는 정적 React/Vite 웹앱이며 AI API 비밀키를 저장소에 넣지 않습니다.

## V3 핵심 workflow

```text
조건 입력
  ↓
GPT 5가지 추천주제
  ↓
주제 1개 선택
  ↓
후킹 제목 5가지
  ↓
제목 1개 선택
  ↓
최종 블로그 프롬프트
  ↓
GPT가 1,200~1,500자 네이버 블로그 작성
```

## 이번 변경의 핵심

### 1. 본문 1,200~1,500자

최종 프롬프트가 **공백 포함 1,200~1,500자**의 네이버 블로그 본문을 요구합니다. 제목·이미지 프롬프트·CTA·해시태그는 본문 글자 수에서 제외합니다.

### 2. AI 느낌 최소화

실제 교육 현장에서 설명하는 듯한 자연스러운 문체를 요구합니다.

- 상투적인 AI 접속어 반복 최소화
- 지나치게 완벽한 광고 문구 최소화
- 구체적인 학부모 고민과 학습 장면 사용
- 허구의 상담 사례·통계·연구 결과 생성 금지
- 짧은 문장과 긴 문장을 자연스럽게 혼합

### 3. 문단과 연결된 이미지

이미지 프롬프트를 글 마지막에 몰아두지 않습니다.

```text
본문 문단
↓
바로 앞 문단과 연결된 이미지 프롬프트
↓
다음 본문
```

2~3개의 이미지 프롬프트를 핵심 문단 바로 다음에 배치합니다.

### 4. 10개 → 5개 주제 workflow

기존의 10개 주제 복사·붙여넣기 방식을 제거하고 `GPT 5가지 추천주제` 버튼으로 정확히 5개를 기획합니다.

그 다음 선택한 주제로 `후킹 제목 5가지 생성` 버튼을 사용합니다.

## 사용법

### STEP 1. 콘텐츠 조건 입력

- 타겟 독자
- 과목 / 학습영역
- 추천 제품
- 지역 / 러닝센터명
- 포스팅 유형
- 이미지 스타일
- 원장님 요청사항

### STEP 2. GPT 5가지 추천주제

버튼을 누르면 조건을 반영한 GPT 프롬프트가 ChatGPT에서 열립니다. GPT 결과 5개를 복사하면 웹앱이 클립보드 자동 불러오기를 시도합니다. 브라우저 권한이 막히면 `결과 불러오기`를 한 번 누르면 됩니다.

### STEP 3. 후킹 제목 5가지

주제를 선택한 후 `후킹 제목 5가지 생성`을 누릅니다. 5개 제목 중 하나를 선택하면 확정 제목이 최종 프롬프트에 반영됩니다.

### STEP 4. 최종 프롬프트

`최종 프롬프트 복사` 후 GPT에 실행합니다.

## GPT 직접 연결용 파일

`GPT_INSTRUCTIONS.md`에는 다음 운영 규칙이 정리되어 있습니다.

- 정확히 5개 주제 추천
- 정확히 5개 후킹 제목 생성
- 본문 1,200~1,500자
- AI 느낌 최소화
- A.E.A 구조
- 교육 90 : 홍보 10
- 문단 연계 이미지 프롬프트 2~3개
- 센터 정보 임의 생성 금지


## GitHub Pages 배포

`main` 브랜치에 변경사항이 push되면 `.github/workflows/deploy-pages.yml`이 자동으로 `npm ci → npm run build → GitHub Pages 배포`를 실행합니다.

## 보안 원칙

GitHub Pages는 정적 웹 호스팅이므로 OpenAI/Gemini API 키를 브라우저 코드에 넣지 않습니다.

현재 구조에서 GPT 생성은 사용자가 사용하는 ChatGPT/GPT가 담당하고, 웹앱은 입력값·눈높이 지식·프롬프트를 설계합니다.

웹앱에서 AI 결과를 완전 자동 수신하려면 별도의 서버리스/Edge API와 서버 측 Secret 관리가 필요합니다.
